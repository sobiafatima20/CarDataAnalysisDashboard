# CarDataAnalysisDashboard 🚗

## 📌 Project Overview

Car Data Analysis Dashboard is a data analysis project focused on exploring and understanding car-related data through Exploratory Data Analysis (EDA) and interactive visualizations.

The project provides insights into car prices, manufacturing years, kilometers driven, and other important features. It helps identify patterns, trends, relationships, and outliers in the dataset.

## 🎯 Objectives

- Perform Exploratory Data Analysis (EDA).
- Clean and preprocess the dataset.
- Analyze numerical and categorical features.
- Identify and handle missing values and outliers.
- Visualize data using interactive charts and graphs.
- Discover meaningful insights from car-related data.

## 🚀 How to Run the Project

**1. Clone the repository**

```bash
git clone https://github.com/sobiafatima20/CarDataAnalysisDashboard.git
```

**2. Navigate to the project directory**

```bash
cd CarDataAnalysisDashboard
```

**3. Create a virtual environment**

```bash
python -m venv .venv
```

**4. Activate the virtual environment**

```bash
.venv\Scripts\activate
```

**5. Install dependencies**

```bash
pip install -r requirements.txt
```

**6. Run the Streamlit dashboard**

```bash
streamlit run app.py
```
